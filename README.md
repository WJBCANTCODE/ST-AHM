## Dataset Sources

- **Tmall**: The IJCAI-15 Repeat Buyers Prediction Dataset released by Alibaba Tianchi, containing user shopping behavior data from Tmall. https://tianchi.aliyun.com/dataset/42
- **Nowplaying**: The #nowplaying dataset, compiled from music listening information posted by users on Twitter. https://doi.org/10.5281/zenodo.2594483
- **30Music**: Music listening records and playlists collected through the Last.fm API. See the original paper by Turrin et al. https://ceur-ws.org/Vol-1441/recsys2015_poster13.pdf

## 数据集来源

- **Tmall**：阿里巴巴天池发布的 IJCAI-15 Repeat Buyers Prediction Dataset，包含天猫用户购物行为数据。https://tianchi.aliyun.com/dataset/42
- **Nowplaying**：从用户在 Twitter 发布的音乐收听信息整理而成的 #nowplaying 数据集。https://doi.org/10.5281/zenodo.2594483
- **30Music**：通过 Last.fm API 收集的音乐收听记录与播放列表数据；原始数据集见 Turrin 等人的论文。https://ceur-ws.org/Vol-1441/recsys2015_poster13.pdf
